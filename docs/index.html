How Guppy works

No magic: a small transformer, trained from scratch on conversations a script wrote about being a fish. The same recipe as the big models, just small enough to fit in a browser tab.

1Write the data

A generator composes ~60k short chats from templates: 86 topics, hundreds of fish-isms.

→
2Tokenize

A byte-level BPE tokenizer with 4,096 tokens turns text into numbers.

→
3Train

A 6-layer transformer learns one thing: predict the next token.

→
4Sample

At chat time it predicts a token, picks one, repeats, until it says “end”.

The model

Parameters8.75 M
Layers × heads6 × 6, width 384, FFN 768 (ReLU)
Vocabulary4,096 byte-level BPE tokens
Context window192 tokens 128 in the original
Norm / positionLayerNorm, learned position embeddings
Output headweight-tied with the token embeddings

It’s a vanilla decoder-only transformer. In the browser it runs as an 8-bit quantized ONNX file (~10 MB) on WebAssembly.

What a training example looks like

<|im_start|>system
you: guppy | tank: castle, snail | mood: hungry | doing: swimming<|im_end|>
<|im_start|>user
are you hungry<|im_end|>
<|im_start|>assistant
yes. so hungry. please feed me.<|im_end|>

The grey markers are special tokens. The model is trained to continue this text, so “being Guppy” just means continuing it the way the data does.

Why it sounds like a fish

Every reply in the training data is short, lowercase, and about water, food, light and bubbles. The personality isn’t a prompt. It’s baked into the weights.

Why it’s a bit dumb

8.7 M parameters can memorise patterns, not facts about the world. Ask it who wrote Hamlet and it was taught to shrug and ask about food.

Why it varies

Replies are sampled (temperature ≈ 0.8, top-k 60), not looked up, and recent answers are resampled so Guppy doesn’t repeat itself.

Tank, memory, mates

A bare language model has no body. Everything that makes Guppy feel alive is plain text fed to it, plus a little animation around it.

🧠 It knows its tank

Before every message the page writes a one-line state describing the tank: what’s in it, who’s with Guppy, its mood (hungry, full, sleepy, scared) and what it’s doing. The model was trained on thousands of random states, so “what’s in your tank?” can be answered from the line instead of invented.

💬 It remembers (briefly)

The conversation so far is pasted into the prompt on every turn. The window is only 192 tokens, so when it fills up the oldest exchanges are dropped. Guppy can recall your name for a few turns, then it’s gone.

🐟 Friends with personalities

Add a fish and it gets its own state line (you: bob the grumpy betta). The same weights speak in four voices: cheerful, grumpy, shy and greedy. Occasionally two fish chat to each other, each one’s reply fed to the other as if a user had said it.

🎪 Tricks & reactions

Spins, loops and jumps are drawn by ordinary animation code. The model just gets a line like “do a spin” and reacts; it can’t actually see the animation.

🍽 Hunger is a timer

The page counts how long since each fish ate and writes mood: hungry or full into the state. Feed it, ask “are you hungry?”, and watch the answer change.

🎓 Teaching it (desktop app)

In the desktop client, /train "Money is a currency." turns a fact into practice chats and genuinely fine-tunes the weights for a minute, mixing in old data so it doesn’t forget how to be a fish.

Honest limits: this is a ~9M model, so it sometimes garbles names, miscounts what’s in the tank, or answers a neighbouring question. The model on this page is ….

Run it yourself

Everything is open source. You can train your own fish in a few minutes.

git clone https://github.com/jgm240/GuppyLM_Advanced && cd GuppyLM_Advanced
python3 -m venv .venv && .venv/bin/pip install torch tokenizers numpy

# make the data (86 topics, state lines, mates, follow-ups) and train a model
.venv/bin/python -m guppylm prepare
.venv/bin/python -m guppylm world-data
.venv/bin/python -m guppylm train --init checkpoints/best_model.pt --data data_world --out checkpoints_world

# talk to it
.venv/bin/python -m guppylm chat
.venv/bin/python -m guppylm tank       # colored ASCII aquarium
.venv/bin/pip install PySide6-Essentials && .venv/bin/python -m guppylm tank-gui   # desktop aquarium

# put your model on this page
.venv/bin/pip install onnx onnxruntime onnxscript && .venv/bin/python tools/export_onnx.py
GuppyLM_Advanced is a fork of arman-bd/guppylm (MIT), the original “train your own tiny LLM” project. This fork adds multi-turn memory, a tank-state prompt, tank mates, tricks, events, /train, two aquarium clients and this page. The byte-level BPE tokenizer in this page is a JavaScript port of the Hugging Face implementation, adapted from the original demo.

Everything runs locally in your browser. Nothing you type is sent anywhere.
